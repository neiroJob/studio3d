# Code of Conduct / Правила поведения

**English** · [Русский](#русский)

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive; no harassment, insults, discrimination or personal attacks; keep
discussions about the work, not the person; do not publish other people's private information.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat
offenders. Report unacceptable behaviour privately in Telegram: [@free_bird1987](https://t.me/free_bird1987).

## Русский

Проект следует [Contributor Covenant 2.1](https://www.contributor-covenant.org/ru/version/2/1/code_of_conduct/).

Коротко: уважительно и по делу; без травли, оскорблений, дискриминации и переходов на личности; обсуждаем работу, а не
человека; не публикуем чужие личные данные.

Сопровождающий может править или удалять комментарии, Issue и pull request, нарушающие правила, и блокировать тех, кто
нарушает их повторно. Сообщить о нарушении лично: Telegram [@free_bird1987](https://t.me/free_bird1987).
