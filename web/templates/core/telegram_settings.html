Как создать и подключить бота — по шагам
  1. Откройте в Telegram официальный @BotFather, отправьте /newbot. Задайте название и уникальное имя, оканчивающееся на bot.
  2. Скопируйте токен BotFather в файл .env на сервере: TELEGRAM_BOT_TOKEN=ваш_токен. Не публикуйте токен, не отправляйте его оператору и не коммитьте в Git.
  3. Из папки проекта на сервере выполните bash update.sh. Проверьте docker compose logs --tail=50 bot. Порт для бота открывать не нужно: он сам подключается к Telegram.
  4. Нажмите «Добавить получателя». Для личного чата выберите пользователя проекта; для группы — тип «Группа операторов». Выберите принтеры или оставьте выбор пустым для всех.
  5. Создайте одноразовый код. Для личного чата сотрудник открывает ссылку и нажимает «Запустить». Для группы добавьте бота и отправьте в ней /pair КОД. Код действует 10 минут и используется один раз.
  6. Нажмите «Тест» возле привязанного чата. Затем включите уведомления и выберите получателей и интервал ниже.

Привязка личного чата не выполняется только по имени Telegram: доступ подтверждает одноразовый код администратора. В группе статус и фото доступны её участникам. Светом управляет только привязанный сотрудник с правом управления печатью; для этого ему нужен также привязанный личный чат.

Бот никогда не запускает, не приостанавливает и не отменяет печать, не управляет нагревом и не отмечает снятие изделия. Команды: /status, /photo, /alerts, /history, /hours, /light, /mute, /unmute, /help.

Свежий снимок JPEG или кадр WebRTC загружается в Telegram самим сервером. Telegram не получает доступ к локальному адресу камеры. Если фото недоступно, состояние отправится текстом с пояснением. WebRTC может подключаться до 35 секунд.

Для нативной WebRTC-камеры K1C серверу нужен двусторонний UDP-доступ к принтеру. В Linux добавьте в серверный .env строку COMPOSE_FILE=docker-compose.yml:docker-compose.telegram-lan.yml и выполните bash update.sh: бот будет использовать сеть хоста. Проверяйте именно полученное фото — текстовая доставка с ошибкой камеры не подтверждает работу видео. Подробности и диагностика — в docs/telegram.md.
