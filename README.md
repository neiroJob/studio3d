# Студия 3D — система управления студией 3D-печати

Бесплатный self-hosted сервер для студии 3D-печати:
- мониторинг принтеров и камеры;
- уведомления в Telegram;
- CRM и склад пластика;
- точный расчёт себестоимости;
- подключение собственных устройств студии по MQTT.

Работает в локальной сети, разворачивается в Docker.

> Статус: этап 1 из 11 — согласование ТЗ и прототипа интерфейса. Кода пока нет.

## 1. Возможности

| Модуль | Что делает |
| --- | --- |
| Принтеры | Добавление по модели и IP, живое состояние, управление печатью, наработка в часах печати и включения, ТО |
| Камеры | Снимки по расписанию, живое видео, таймлапсы |
| Telegram | Уведомления сотрудникам и клиентам: старт, прогресс со снимком, ошибки, окончание, заказ готов |
| CRM | Клиенты (физ. и юр. лица), заказы, изделия, задания печати, файлы, фото |
| Склад | Катушки пластика с автоматическим списанием, расходники |
| Себестоимость | Пластик, электроэнергия, амортизация, аренда, постобработка, брак |
| Устройства | MQTT: климат-контроллер, розетки с отключением, правила автоматики |
| Расширения | Новые модели принтеров и типы устройств — загрузкой пакета без правки кода |
| Роли | Админ, менеджер, оператор; несколько ролей на одном логине |

## 3. Стек

| Компонент | Технология |
| --- | --- |
| Веб и API | Django 5, HTMX, Alpine.js |
| Связь с принтерами | Отдельный асинхронный сервис на Python (asyncio) |
| Telegram-бот | aiogram 3 |
| Фоновые задачи | Celery + Redis |
| База данных | PostgreSQL 16 |
| Устройства | MQTT, Mosquitto 2 |
| Развёртывание | Docker Compose |

## 4. Поддерживаемые принтеры

Планируется в версии 1 (на принтерах ничего не устанавливается, работа со штатной прошивкой):

| Производитель | Модели | Драйвер |
| --- | --- | --- |
| QIDI | Plus 4, Q1 Pro, Q2 | moonraker |
| Elegoo | Neptune 4 Max | moonraker |
| Creality | K1, K1C | creality_native (K1C ревизии 2025 — moonraker) |

## 5. Установка

Появится вместе с первым рабочим релизом. План: Ubuntu Server, Docker, `git clone`, `docker compose up -d`, мастер первого запуска в браузере. Как подготовить сервер — в документе «Подготовка сервера».

## 6. Разработка

- Репозиторий памяти `ai_studio3d_memory` держите рядом с этим репозиторием: `~/projects/studio3d` и `~/projects/ai_studio3d_memory`. `CLAUDE.md` подгружает память по относительному пути.
- Номера задач YouGile — `STU-N` — указываются в сообщениях коммитов.
- Память проекта в этот репозиторий не коммитится.
