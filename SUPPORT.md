# Support / Поддержка

**English**

- **Questions, ideas, bugs:** [GitHub Issues](https://github.com/neiroJob/studio3d/issues/new/choose).
- **New printer model:** use the "Printer support request" template and attach `tools/moonraker_dump.py` output.
- **Security:** see [SECURITY.md](SECURITY.md) — never in public issues.
- **Commercial license, paid installation or support:** "Commercial license" issue template or Telegram
  [@free_bird1987](https://t.me/free_bird1987). See [LICENSING.md](LICENSING.md).

Studio3D is maintained in spare time; there is no guaranteed response time for free support.

**Русский**

- **Вопросы, идеи, ошибки:** [GitHub Issues](https://github.com/neiroJob/studio3d/issues/new/choose).
- **Новая модель принтера:** шаблон «Printer support request» и вывод `tools/moonraker_dump.py`.
- **Безопасность:** [SECURITY.md](SECURITY.md), не в публичных Issue.
- **Коммерческая лицензия, платная установка или поддержка:** шаблон «Commercial license» или Telegram
  [@free_bird1987](https://t.me/free_bird1987). См. [LICENSING.md](LICENSING.md).

Бесплатная поддержка — по мере возможности, без гарантированного срока ответа.
